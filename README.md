## 🚀 About Pixora

Pixora is a modern social media platform inspired by Instagram, Threads, and Facebook. It allows users to share photos, connect with friends, chat in real time, post stories, and receive notifications through a fast, secure, and responsive experience.

---

## ✨ Features

* 🔐 Secure Authentication (JWT)
* 👤 User Profiles
* 📝 Create, Edit & Delete Posts
* ❤️ Like & Unlike Posts
* 💬 Comments
* 👥 Follow & Unfollow Users
* 📖 Stories (24 Hours)
* 💬 Real-Time Chat
* 🔔 Notifications
* 🔍 User Search
* 📱 Responsive Design
* 🌙 Dark Mode
* ☁️ Cloud Image Upload
